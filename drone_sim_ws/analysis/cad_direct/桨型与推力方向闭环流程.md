# 桨型与推力正方向闭环流程

当前 CAD 只能冻结电机位置和无符号圆柱轴，不能冻结桨叶手性或推力正方向。
不得根据 CW/CCW 或“推式/拉式”单独推断推力符号。

优先采用厂家证据：对电机 1～8 记录真实安装的桨叶零件号、正桨/反桨标识、
厂家对 CW/CCW 的观察方向定义，并附数据表或桨叶标识照片。尤其要确认
4、5、7、8 与 1、2、3、6 是否为相反螺距。

如果没有厂家资料，执行低风险单桨台架测试：拆下飞机上的桨/电机组合并可靠
固定，远离人员；使用防护罩和远程断电。固定同一观察方向，记录命令旋向、
RPM、轴向力传感器正方向及带符号力值。先在低转速确认符号，再逐级增加转速。
本项目需要的是推力符号；最大推力 11.76798 N 已按用户数据冻结，除非以后用
同电压、同电机、同桨的标定表替换。

台架记录必须明确选择一种旋向观察定义：

- `LOOKING_FROM_MOTOR_TOWARD_PROPELLER`；或
- `LOOKING_ALONG_CAD_PROPELLER_SIDE_RAY_TOWARD_MOTOR`。

力传感器正方向也必须明确写为 `CAD_PROPELLER_SIDE_RAY` 或
`OPPOSITE_CAD_PROPELLER_SIDE_RAY`。校验器会由带符号力值自动反算推力符号；
若它与人工填写的 `thrust_sign_along_cad_propeller_ray` 冲突，证据不能通过。
厂家资料同样必须写清旋向观察方向及桨型/推力方向定义，不能只填写一个
“正桨”或“反桨”标签。

把证据填入 `motor_thrust_evidence.template.json` 的副本，然后运行：

```bash
cd /mnt/e/清洁无人机/drone_sim_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
python3 scripts/validate_motor_thrust_evidence.py \
  analysis/cad_direct/motor_thrust_evidence.json \
  --report analysis/cad_direct/motor_thrust_evidence.validation.json
```

只有输出 `MOTOR_THRUST_EVIDENCE_PASS` 且 `promotion_allowed=true`，才允许更新
正式推力轴、控制分配矩阵和 7.735 kg PX4 airframe。模板本身故意不能通过。
`evidence_refs` 必须指向证据 JSON 所在目录下的本地快照文件，不能只填 URL
或已经失效的微信临时路径；校验报告会记录文件大小和 SHA-256，便于后续审计。
