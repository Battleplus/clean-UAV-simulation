# Base 1 全方向机械臂／PX4／Gazebo 联合验收

该入口覆盖机体坐标系 ROS FLU 中的十个末端方向：

```text
front, rear, left, right, up, down,
front_left, front_right, rear_left, rear_right
```

每个方向严格执行：

```text
retracted → extend → hold → retract → PX4 速度稳定门
```

下一个方向不会从上一个方向的伸展姿态继续运动。任何一个方向不能完整回收、轨迹预演失败或 PX4 未重新稳定时，序列失败并请求降落。

## 验收阈值

伸出、保持和回收三个阶段分别计算，不只计算整次飞行的总值：

- 水平位置峰峰值 `<= 0.05 m`
- 高度峰峰值 `<= 0.05 m`
- 最大真实倾角 `<= 1.0 deg`
- 电机物理饱和样本数 `= 0`
- 无 PX4 failsafe
- 每个方向均发出 `DIRECTIONAL_DIRECTION_COMPLETE`
- 最后执行正常 PX4 LAND 并确认解除武装

## 使用方法

在 WSL 工作空间直接运行：

```bash
bash scripts/run_directional_workspace_acceptance_4kg.sh
```

入口先构建当前源码、重新生成轨迹计划，再默认干净启动 headless 4 kg Base 1
后端并在一次起飞中完成十个方向，因此不会误用旧 install。只有明确确认已有后端
正确时才设置 `DIRECTIONAL_RESTART_BACKEND=0`。完整默认序列的预演运动时长约
`690 s`，测试超时会根据计划自动计算。结果写入：

```text
analysis/base1/directional_workspace_flight_plan_4kg.json
analysis/base1/directional_workspace_flight_acceptance_4kg.log
analysis/base1/directional_workspace_flight_acceptance_4kg.exit
```

日志中的权威逐阶段记录为：

```text
DIRECTIONAL_FLIGHT_STAGE_METRICS ... pass=True
DIRECTIONAL_FLIGHT_DIRECTION_RESULT ... returned=True pass=True
DDS_ARM_FLIGHT_PASS
```

规划文件状态明确为 `PREFLIGHTED_NOT_FLIGHT_ACCEPTED`。只有实际日志同时具有全部方向的阶段通过记录、正常回收和最终 `DDS_ARM_FLIGHT_PASS`，才可称为通过联合验收。

规划文件还保存当前工作空间报告、URDF、运动参考、飞行配置、规划器、轨迹
预演器和工作空间实现的 SHA-256。序列执行前会重新计算实时输入和安全实现的
哈希；任一文件变化都会以
`directional plan is stale for the live model` 拒绝执行，必须重新扫描和规划，
不能把旧计划套到新模型上。

轨迹预演与 schema 2 包线共用八个 CAD 旋翼扫掠区。折叠姿态的一个已知粗箱
重叠只在收回姿态附近局部校准，不会在其余工作空间被全局忽略。
