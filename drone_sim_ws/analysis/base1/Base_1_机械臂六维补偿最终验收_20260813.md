# Base 1 机械臂六维补偿最终验收（2026-08-13）

## 结论

Base 1 的 4 kg CAD 机型已完成 SO101 动作 6 的联合补偿验收，同时保留原有起飞、悬停、WASD、偏航和正常降落能力。

动作 6 的正式飞行轨迹为：末端沿 CAD 工具轴伸出 `0.10 m / 90 s`，保持 `8 s`，再用 `90 s` 原路收回。全程保留 Gazebo 多刚体耦合，没有固定机械臂、冻结机身或关闭真实质量/惯量变化。

## 正式补偿结构

1. PX4 继续负责速度、位置、姿态和角速度级联闭环。
2. SO101 运动学/动力学估计器以 `100 Hz` 计算机械臂总质心、惯量以及各连杆动量变化。
3. 静态通道根据质心偏移计算重力矩 `r_com × mg`。
4. 动态六维通道计算连杆刚体动量变化造成的 3 轴反作用力和 3 轴反作用力矩。
5. 八旋翼分配器把上述六维补偿与 PX4 原始 8 路电机命令叠加，并检查源新鲜度、余量、残差和饱和。
6. 关节阻尼与摩擦不再作为外部基座力矩重复注入；Gazebo 多刚体关节已经传递这对内部作用力。此前重复注入会产生约 `0.04 N·m` 的伪动态力矩并放大前后摆动。
7. Gazebo 视觉里程计仅向 PX4 融合速度和偏航（`EKF2_EV_CTRL=12`），未融合绝对位置。实机迁移需要 VIO、光学定位或等价速度/偏航来源，不能把 Gazebo truth 当作实机传感器。

默认补偿参数：

```text
reaction_force_gain       = 1
reaction_torque_gain      = 1
gravity_torque_gain       = 1
gravity_torque_limit      = 0.65 N·m
maximum_motor_delta       = 0.70 N
direct_position_feedback = false
```

## Base 1 WASD 不退化验收

水平目标速度仍为 `0.40 m/s`，但输入整形改为：

```text
水平最大加速度 = 0.15 m/s²
水平最大 jerk  = 0.30 m/s³
偏航最大加速度 = 15 deg/s²
```

干净 A/B 中，原 `0.30 m/s² / 0.60 m/s³` 的水平速度峰值为 `0.617 m/s`（54% 超调）；新值的峰值为 `0.437 m/s`（9.1% 超调），最大倾角由 `4.0°` 降到 `2.0°`。起飞、W/S/A/D、R/F、Q/E、H 悬停、正常 LAND 均完成，无 failsafe、无电机饱和。

最终当前版本验收日志：`final_current_dynamic6d_wasd_strict_yawacc15.log`。水平速度峰值 `0.4366 m/s`（9.14% 超调），偏航峰值 `15.4 deg/s`（2.67% 超调），最大倾角 `2.0 deg`，结果为 `DDS_VELOCITY_WASD_PASS`。
