# 基于可变惯性参数模型的机械臂扰动补偿实施规划

## 1. 参考方法与适用范围

本规划组合使用两条公开、可核验的技术路线：

1. PX4 官方多旋翼串级控制架构：位置 P、速度 PID、加速度到推力/姿态、姿态 P、角速度 PID、控制分配。
2. *Robust Control of An Aerial Manipulator Based on a Variable Inertia Parameters Model*：将机械臂运动引起的耦合效应写成随关节状态变化的 CoM、惯量及其导数，并估计等效扰动力和扰动力矩。

公开链接：

- https://docs.px4.io/v1.17/en/flight_stack/controller_diagrams
- https://arxiv.org/abs/2401.04316
- https://pubmed.ncbi.nlm.nih.gov/39423088/

项目中的飞书整理稿还提到下列开源项目，但它们分别偏模型示例和整体运动规划，不能替代飞行扰动补偿器：

- https://github.com/medhijk/Aerial-Manipulator
- https://github.com/SYSU-HILAB/am-planner

## 2. 先冻结已有结论

- 4 kg、补偿关闭、完整伸展/收回各 90 s 的确定性 Headless 测试已经通过。
- 该基线的水平漂移为 0.108 m，高度跨度为 0.199 m，最大真值倾角为 1.345 deg，电机饱和样本为 0。
- 静态 COM gain=0.5 的确定性成对 A/B 没有通过：水平漂移从 0.072 m 恶化到 0.151 m，最大倾角从 0.985 deg 恶化到 1.315 deg。
- 因此当前的简单静态 COM 前馈和临时 25% 混合补偿都只能作为实验，不能成为默认配置。
- 当前手动按键 6 使用 0.10 m Cartesian 路径，每程 30 s；它不等价于已验收的 90 s 预设轨迹。

## 3. 目标控制结构

```text
位置目标
  -> PX4 位置 P
  -> 速度目标
  -> PX4 速度 PID
  -> 基础加速度目标
  + 机械臂估计扰动力补偿 (-F_dis / M)
  -> 期望总力/期望姿态
  -> PX4 姿态 P
  -> PX4 角速度 PID
  -> 基础力矩目标
  + 机械臂估计扰动力矩补偿 (-tau_dis)
  -> 6x8 受约束控制分配
  -> 8 个电机
```

PX4 原反馈环负责模型误差和低频残差；机械臂模型只提供有界前馈，不能直接取代 PX4，也不能绕过饱和、反积分饱和和安全状态机。

## 4. 可变惯性参数模型

由当前关节位置 `q`、速度 `q_dot`、加速度 `q_ddot` 和每个刚体的质量属性计算：

```text
r_c(q)              整机 CoM 在 base_link/FLU 中的位置
I_c(q)              整机在 CoM 处的完整 3x3 惯量张量
r_c_dot, r_c_ddot   CoM 一阶、二阶变化
I_c_dot, I_c_ddot   惯量张量一阶、二阶变化
```

整机 CoM 采用多刚体质量加权：

```text
r_c = sum(m_i * r_i(q)) / sum(m_i)
```

扰动估计至少分成三部分：

```text
F_dis   = CoM 平动与机械臂连杆加减速产生的等效反作用力
tau_g   = r_c x (M * g_body) 产生的持续重力矩
tau_dyn = I_dot/I_ddot、角动量变化和关节运动产生的动态反作用力矩
```

第一版不直接照搬论文的完整 H-infinity 控制器，而是先复现其“可变惯性扰动估计器”，将估计量作为 PX4 的有界前馈。只有该结构在成对 A/B 中仍不能通过，才评估自定义 H-infinity/几何姿态控制器。

## 5. 坐标系与注入点

- 机械臂动力学内部统一使用 ROS `base_link` FLU。
- PX4 平动控制使用本地 NED 惯性坐标。
- PX4 力矩和控制分配使用 FRD 机体系。
- 每个补偿数据包必须携带 frame、时间戳和单位；不得依靠隐含符号。

转换流程：

```text
F_dis_FLU -> 当前姿态旋转到 NED -> -F_dis_NED / M -> acceleration feed-forward
tau_dis_FLU -> FLU/FRD 符号变换 -> -tau_dis_FRD -> wrench allocator
```

## 6. 对现有代码的改造

### 6.1 状态与模型估计

改造 `arm_coupling_monitor.py`：

- 由当前 3 Hz 提升为 100 Hz 内部更新，日志仍可降采样。
- 使用带时间戳的完整关节状态。
- 对 `q_dot/q_ddot` 使用限带微分器，不直接放大 Gazebo 数值噪声。
- 输出 `r_c/I_c` 以及一阶、二阶变化和估计 `F_dis/tau_dis`。
- 同时发布 freshness、置信度、限幅状态和模型残差。

### 6.2 外环扰动力补偿

改造 `dds_wasd_control.py`：

- 保留 PX4 原位置/速度串级控制。
- 只在机械臂状态新鲜、飞机已稳定悬停且补偿器健康时注入 `-F_dis/M`。
- 100 ms 数据超时立即平滑退回零补偿。
- 初始增益从 0.10 开始，只允许通过独立 A/B 后递增。

### 6.3 内环扰动力矩补偿

替换当前“直接给电机加偏置”的实验路径：

- 将 PX4 基础力/力矩和机械臂补偿力/力矩组合成同一个 6 维目标 wrench。
- 使用正式 6x8 分配矩阵做带约束最小二乘。
- 约束每台电机最小/最大推力、变化率和总垂向余量。
- 优先保持总垂向力与滚转/俯仰，偏航按剩余权限分配。
- 分配失败或残差越界时冻结机械臂并回退，不通过放宽阈值掩盖。

### 6.4 残差扰动观测器

模型前馈通过后，再启用 `arm_disturbance_observer.py`：

- 观测器只补偿“实测机体响应 - 模型预测响应”的低频残差。
- 不与模型前馈重复补偿同一项。
- 使用 3--5 Hz 低通、独立增益和独立上限。
- 先被动记录，再做 observer off/on 的确定性成对 A/B。

## 7. 轨迹与通信安全

- 空中按键 6 第一阶段恢复为每程 90 s；地面演示可保持 8 s。
- 每个 5 mm Cartesian 路点检查水平/垂直速度、倾角、位置漂移、电机余量和 DDS 数据年龄。
- 超限时暂停下一路点并平滑收回，不能继续累积动作。
- Gazebo server 使用 Headless 独立进程，GUI 作为独立客户端连接，避免渲染阻塞传感器链。
- DDS、PX4 状态或电机命令超过规定时间不刷新时，禁止保持最后一次电机推力；进入有界降推力/安全落地流程。

## 8. 实施顺序与验收门

### 阶段 A：恢复可重复基线

1. 关闭所有机械臂补偿。
2. Headless、固定 seed、全新 PX4 状态运行 90 s 完整伸展/收回。
3. 至少重复 3 次。

验收：每次无 failsafe、无 DDS 间断、无电机饱和；漂移 <=0.15 m，高度跨度 <=0.30 m，倾角 <=3 deg。

### 阶段 B：验证扰动估计器

1. 补偿输出保持关闭。
2. 将估计 wrench 与 Gazebo 多刚体真值、机体角动量变化交叉验证。
3. 分别测试静态姿态、单关节、慢速多关节和完整伸展。

验收：符号、坐标和量纲全部通过；静态重力矩与动态反作用力矩可分离；无时间戳跳变。

### 阶段 C：单通道 A/B

依次测试，不能混合：

1. 仅平动力补偿。
2. 仅静态重力矩补偿。
3. 仅动态反作用力矩补偿。

每项均执行相同 seed、相同轨迹、相同初始状态的 off/on 成对测试。

验收：水平漂移和最大倾角均不恶化，高度跨度恶化不超过 0.02 m，无饱和、无 failsafe。

### 阶段 D：组合模型前馈

按 90 s、60 s、30 s 逐步加快，再测试手动按键 6 的 Cartesian 路径。

验收：相对无补偿基线，水平漂移和 RMS 倾角至少降低 20%；所有安全门仍通过。

### 阶段 E：残差观测器与 GUI

1. 先做观测器被动记录。
2. 再做确定性 Headless observer off/on。
3. 最后才连接独立 GUI 客户端做人工 WASD + 按键 6 联合验收。

GUI 运行出现 DDS、MAG、BARO 或传感器超时，必须判为运行链路失败，不能记为补偿算法失败或成功。
