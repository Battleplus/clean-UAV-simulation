This record separates what is verified in Gazebo/PX4 from what is still a
provisional physical assumption. The 7.735 kg baseline is not overwritten by
the experiments below.

## Step 4-5: rotor model and allocation

- Input is eight normalized actuator commands in `[0, 1]`.
- The supplied static table is used at 14.8 V and capped at 11.76798 N per
  motor (1.2 kgf). There is still no RPM, `C_T`, or `C_Q` measurement.
- Each command produces a per-motor force and torque record. The allocation
  matrix is 6 x 8, rank 6, condition number about 23.3225.
- The bounded hover solution for 7.735 kg has residual norm `2.98e-14 N/Nm`
  and no saturation. An impossible `Fz=-200 N` request correctly reports
  upper saturation and a large residual.
- `Q/T=0.001 m` remains a temporary reaction-torque estimate. Propeller pitch
  signs for 4/5/7/8 remain a CAD/manufacturer confirmation item.

The allocation and PX4 airframe generators now accept an optional signed
`thrust_axis_body` per rotor. When absent, they deliberately fall back to the
CAD shaft axis and retain the current opposite-pitch hypothesis. This keeps a
future pitch-confirmed table from being silently forced into the old all-upward
model.

## Step 10: explicit coupled-dynamics layer (partially accepted)

The Gazebo multibody tree retains the formal link masses, COMs, inertias,
joint damping/friction and physical joint reactions. The new auditable layer
adds:

- real-time composite mass, COM and inertia evaluation from joint states;
- fixed-base reaction-force/torque estimation including joint damping and
  Coulomb friction;
- optional rigid end-effector payload mass/inertia;
- free-body velocity jump from an end-effector contact impulse;
- a bounded NED acceleration feed-forward topic (default limit `0.6 m/s^2`),
