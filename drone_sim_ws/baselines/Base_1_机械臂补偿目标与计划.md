# Base 1 机械臂补偿目标与计划

日期：2026-08-12

## 总目标

以 Git 标签 `base-1`（提交 `b340ed6`）的 4 kg 稳定飞行版本为唯一开发基线，在不测试、不迁移、不调整 7.735 kg 配置的前提下，把 SO101 机械臂动作能力接入当前机架，并用可关闭的扰动补偿降低机械臂运动造成的漂移和姿态波动。

完成后必须同时满足：

1. 机械臂关闭时，飞机保持 Base 1 原有起飞、悬停、WASD 锁存速度控制、偏航和降落能力；
2. 机械臂节点启动但静止时，飞行行为与 Base 1 一致；
3. 机械臂动作时，飞机的悬停目标不被重置，WASD 目标不被机械臂节点覆盖；
4. 补偿器关闭、异常或数据超时时，补偿平滑回零，飞机继续由 Base 1 的 PX4 闭环控制；
5. 只有在确定性 A/B 测试中优于无补偿基线的补偿通道才允许保留。

## 本阶段明确不做

- 不测试 7.735 kg；
- 不复制 4 kg 增益到 7.735 kg；
- 不重写 PX4 位置、速度、姿态或角速度反馈环；
- 不修改 Base 1 的 WASD 锁存语义；
- 不用机械臂动作节点发布新的飞机位置目标；
- 不在 6×8 分配之后直接给单台电机增加偏置；
- 不先接入 MoveIt 2、LeRobot、视觉或 RL；
- 不通过放宽安全门掩盖漂移、饱和或通信故障。

## 修改结构

```text
Base 1 原飞行链（保持）
WASD/悬停目标
  → PX4 位置/速度/姿态/角速度反馈
  → 基础期望 wrench

新增机械臂链（可关闭）
SO101 q, q_dot, q_ddot
  → 动态 CoM 与完整惯量估计
  → 静态重力矩 + 动态反作用力/力矩
  → freshness/限幅/电机余量/飞行状态安全门
  → 有界补偿 wrench

基础 wrench + 有界补偿 wrench
  → 一次受约束 6×8 控制分配
  → 8 路电机
```

### 必须保持不动的部分

- Base 1 正常启动入口与默认参数；
- PX4 原有反馈环；
- WASD 速度锁存、H 零速度悬停、起降和偏航逻辑；
- 正式机架几何和已有 6×8 基础效能数据；
- 机械臂补偿默认关闭。

### 允许新增或修改的部分

- 机械臂状态估计与动力学观测节点；
- 带 frame、时间戳和健康状态的补偿消息；
- 分配器前的补偿 wrench 合成入口；
- 补偿限幅、变化率、超时平滑回零和电机余量门；
- 机械臂轨迹的速度、加速度和 jerk 限制；
- A/B 测试、日志和结果分析工具。

## 实施阶段

### 阶段 A：保护 Base 1

1. 从 `base-1` 建立独立开发分支；
2. 保存飞行核心文件清单和 SHA-256；
3. 正常启动不带 `-ArmCompensationTest`；
4. 连续运行 Base 1 飞行回归，保存原始日志。

通过门：机械臂关闭和机械臂静止两种状态下，原飞行能力均无回归。

### 阶段 B：重新获得无补偿机械臂基线

依次执行：

1. 只动夹爪；
2. 只动 wrist_roll；
3. 单关节低速；
4. 多关节低速；
5. 每程 90 s 完整伸展/收回。

记录水平漂移、高度跨度、最大/RMS 倾角、角速度、电机余量、饱和率、DDS 数据年龄和 failsafe。

通过门：先复现已有 4 kg、90 s 动作基线；GUI 故障与控制故障分别归类。

### 阶段 C：只读动力学估计

以 100 Hz 计算：

- `r_c(q)`：整机动态质心；
- `I_c(q)`：整机完整 3×3 惯量；
- `F_dis`：机械臂连杆加减速产生的反作用力；
- `tau_g = r_c × Mg`：质心偏移产生的重力矩；
- `tau_dyn`：惯量和角动量变化产生的动态反作用力矩。

此阶段只记录，不注入飞行控制。

通过门：FLU、FRD、NED 坐标、符号、量纲和时间戳全部通过单元及离线交叉验证。

### 阶段 D：建立正确的补偿注入点

1. 平动力补偿转换为 PX4 加速度/总力前馈；
2. 重力矩与动态力矩转换到 FRD；
3. 与 PX4 基础控制目标合成为一个 6D wrench；
4. 只进行一次带推力上下限和变化率限制的 6×8 分配；
5. 数据超过 100 ms、飞行状态不稳定、DDS 异常或电机余量不足时，补偿平滑回零。

通过门：补偿为零时输出与 Base 1 一致；不得出现“最后一次电机输出冻结”。

### 阶段 E：单通道成对 A/B

按顺序分别测试：

1. 仅平动力补偿；
2. 仅静态重力矩补偿；
3. 仅动态反作用力矩补偿。

每项从 `0.05～0.10` 小增益开始，使用相同 seed、初始状态和轨迹做 off/on 成对比较。

单项通过门：

- 水平漂移不恶化；
- 最大及 RMS 倾角不恶化；
- 高度跨度恶化不超过 0.02 m；
- 无电机饱和、无 failsafe、无 DDS 中断；
- 至少一个主要扰动指标有稳定、可重复改善。

当前已否决的静态 CoM `gain=0.5` 不得作为起点复用。

### 阶段 F：组合与动作速度递进

只组合阶段 E 通过的通道，动作速度按以下顺序推进：

```text
90 s/程 → 60 s/程 → 30 s/程 → 人工按键 6
```

每个 Cartesian 路点检查稳定状态、倾角、速度、电机余量和 DDS freshness；超限后停止增加动作，并平滑收回机械臂。

组合通过门：相对无补偿 Base 1 机械臂基线，水平漂移和 RMS 倾角至少降低 20%，原飞行能力零回归。

### 阶段 G：人工联合验收并存新档

1. 正常起飞和悬停；
2. WASD 锁存速度飞行；
3. H 回到零速度悬停；
4. 机械臂慢速动作；
5. 按键 6 伸直、保持、原路收回；
6. 机械臂动作后继续 WASD；
7. 正常降落与解除武装；
8. 主动关闭补偿，确认无缝回到 Base 1 控制。

通过后另建新标签，不移动、不覆盖 `base-1`。

## 最终决策规则

- Base 1 永远保留为已认可的稳定悬停版本；
- 新补偿版本只能在 Base 1 上做增量修改；
- 算法不改善就撤回算法，不调整 Base 1 来迎合补偿器；
- 4 kg 联合控制通过之前，7.735 kg 维持冻结状态；
- 未来迁移正式质量时另立新目标、重新计算全部质量归一化、分配余量和安全限幅。
